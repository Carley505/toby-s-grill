Toby's Grill — Menu Assets Directory
---------------------------------------

Place your menu files in this directory:
1. `menu.pdf` — Drop your PDF menu file here. The website will automatically detect and link to it for downloads.
2. `menu-1.jpg`, `menu-2.jpg` (or PNG) — Drop scanned or designed menu image files here.

If `menu.pdf` is not present, the website automatically falls back to an interactive web menu modal with a WhatsApp order button.
